# CBB hosted collection

The private repository owns the only active collector. GitHub Actions runs five times daily at 09:00, 12:00, 15:00, 18:00 and 21:00 America/New_York. UTC alternates are filtered using the Eastern timezone, including daylight-saving changes. The one-time November 1, 2026 22:45 Eastern run replaces that day's 21:00 paid request; the public pipeline still runs at 21:00. GitHub schedules can be delayed; the site flags an update one hour overdue. Workflow failure notifications follow the owner's GitHub notification preferences.

Manual `workflow_dispatch` defaults to a public-only check. Turning that option off permits one paid attempt, subject to the migrated guards. No HTTP retry is added for paid calls. One concurrency group serializes all workflows. The private `collector-state` branch contains the authoritative usage ledger, raw observations, quote history, settled results and immutable forecasts. An attempt is pushed before contacting the odds provider; failed attempts count and unknown credit consumption reserves three credits. State push failure prevents the paid request. A crash after a paid request retains the reservation.

`frozen-runtime.zip` contains the existing pinned Python source and fitted artifacts. The original release-manifest checks run before paper forecasts. The only collector changes are operating-system-independent secret acquisition, private durable checkpoints, global one-hour spacing and conservative credit accounting. No parameters, calibration, features, selection thresholds or issued records are edited. A wrapper shares canonical ESPN observations between the main schedule and prospective pipeline, rejects cancelled/postponed games, and handles an empty schedule. It never backdates an observation or reconstructs a missed forecast.

The public repository `cgurrie03/cbb-public-data` contains only the existing public datasets and health information. Private sources, quota ledger, provider key and fitted models are excluded. All files are committed together, read back by immutable commit ID, then activated through `current.json`. The website pins that revision for all live datasets and downloads. A failed pipeline retains the previous complete dataset and publishes an error status. Website source releases are independent of data publication.

Secrets are GitHub Actions secrets: `ODDS_API_KEY` and `PUBLIC_DATA_DEPLOY_KEY`. The latter is a write-enabled deploy key scoped to the public data repository. The normal GitHub Actions token writes private state. No personal token or DPAPI file is uploaded. Original source observations from before migration are stored in private `archives/prior-sources-*.zip`, indexed by SHA-256 in `archives/manifest.json`; new sources are recorded in state. Archives preserve bytes and original filenames, including original observation metadata.

Before changing operations, run `python -m unittest test_operations`, the original prospective/model regression suite, and a hosted public-only dispatch with public readback. Never refit from an update job. After any provider failure, inspect health and the durable ledger before considering a new paid attempt; do not reset or replace quota history. Do not resume the two retired local chats while this collector is active.

Formal model review remains a human decision. Collection/timing review is distinct from model promotion. No simulation challenger is implemented by this operational release.
